# Support

## Usage questions

Before opening an issue:

1. Check the requirements and usage instructions in [README.md](README.md).
2. Confirm `gh auth status` succeeds and that the selected account has the required repository or
   organization administration permission.
3. Confirm the GitHub Actions runner works with its own scripts outside Runner Menu.
4. Search existing issues for the same symptom.

If the problem appears specific to Runner Menu, open an issue with your macOS version, Mac
architecture, Runner Menu commit or version, GitHub CLI version, Actions Runner version, and concise
reproduction steps.

Redact usernames and local paths where appropriate. Never attach credentials, registration or
removal tokens, repository secrets, or unredacted runner logs.

## Bugs and feature requests

Use the repository's issue templates. Bug reports should include the smallest safe reproduction;
feature requests should explain the use case as well as the proposed behavior.

## Security issues

Do not use a public issue. Follow the private reporting process in [SECURITY.md](SECURITY.md).
